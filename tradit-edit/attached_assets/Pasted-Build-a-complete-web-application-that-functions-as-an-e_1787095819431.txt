Build a complete web application that functions as an e‑commerce storefront for buying and selling shoes. The business model is similar to GameStop but for footwear: users submit photos of their used shoes, the system evaluates them using AI, assigns store credit, and the credit can be used to buy new discounted shoes.

1. Tech Stack Requirements
Frontend: HTML, CSS, JavaScript

Backend: Node.js + Express

Database: JSON or lightweight DB (e.g., SQLite)

AI Integration: Use a placeholder API function for shoe‑image analysis (brand, model, condition).

Image Handling: Temporary upload endpoint + client‑side preview

Rate Limiting: Prevent spam and excessive AI usage

File Structure:

/public/index.html

/public/styles.css

/public/app.js

/server.js

/routes/upload.js

/routes/store.js

/ai/shoeScan.js (mock AI module)

/data/shoes.json

/data/users.json

2. Core Features
A. User Shoe Submission System
Users upload a photo of their shoe.

The backend stores the image temporarily.

The AI module analyzes:

Brand (Nike, Adidas, etc.)

Model/type (Air Force 1, Dunk, Yeezy, etc.)

Condition (new, lightly worn, worn, damaged)

The system returns:

Estimated resale value

Store credit amount

Users can accept or decline the offer.

B. Storefront for Buying New Shoes
Display catalog of new shoes with discounted prices.

Users can purchase using store credit + cash.

Shopping cart + checkout flow.

C. Anti‑Spam & Rate Limiting
Limit shoe‑scan submissions per user per hour.

Block repeated uploads of identical images.

Queue requests so AI scans don’t overload the server.

Return friendly error messages when limits are hit.
